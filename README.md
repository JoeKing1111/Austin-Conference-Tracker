# Austin Conference & Event Tracker

A Python pipeline that aggregates upcoming Austin, TX conferences and events from multiple sources into a searchable, self-contained HTML page.

## What it does

1. **`fetch_conferences.py`** — pulls event data from three live sources and writes it to a CSV:
   - **Luma (lu.ma)** — parses the embedded SSR JSON from `luma.com/austin`
   - **Meetup.com** — queries the `gql2` GraphQL endpoint with no API key
   - Manual data (10times, Eventbrite, Austin Chamber) preserved from previous runs

2. **`build_page.py`** — reads the CSV and generates a fully self-contained `austin_events.html` with all data baked in as JSON — no server required.

## Requirements

- Python 3.8+
- `pip install -r requirements.txt`

## Usage

### Step 1 — Fetch fresh event data
```bash
python fetch_conferences.py --apikey anything
```
> The `--apikey` flag is kept for compatibility. No API key is actually required by any current source.

### Step 2 — Build the HTML page
```bash
python build_page.py
```

### Or run both in one command
```bash
python fetch_conferences.py --apikey anything && python build_page.py
```

Then open `austin_events.html` in any browser. To share it, upload the single HTML file to any web host — no dependencies, no server needed.

## Project structure

```
Conference Tracker/
├── fetch_conferences.py   # Data fetcher — scrapes Luma & Meetup, writes CSV
├── build_page.py          # Page builder — reads CSV, outputs HTML
├── requirements.txt       # Python dependencies
├── austin_conferences.csv # Event data (auto-generated, can be edited manually)

```

## CSV columns

| Column | Description |
|---|---|
| Conference Name | Event title |
| Industry / Category | Topic area |
| Start Date | YYYY-MM-DD |
| End Date | YYYY-MM-DD |
| Venue Name | Name of the venue |
| Address | Street address |
| Cost | Free / Paid / dollar amount |
| Website URL | Link to the event page |
| Organizer Name | Person or org running the event |
| Contact Email | If available |
| Contact Phone | If available |
| CFP / Talk Submission URL | Speaker submission link if available |
| Source | Which platform the data came from |

## Notes

- **Non-destructive updates** — re-running `fetch_conferences.py` never overwrites manually entered data. It only fills in blank fields and appends new events.
- **Deduplication** — events are keyed on Conference Name + Start Date. Duplicates across sources are merged, not doubled up.
- **Error logging** — any failed source requests are written to `errors.log`.
- **Austin Chamber of Commerce** — their events page is JavaScript-rendered and cannot be scraped automatically. Those events are added manually to the CSV.
